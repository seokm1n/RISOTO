# RAG 원본 자료

대응 원칙의 근거가 되는 PDF를 넣는 곳입니다. **자료를 추가할 때 여기에 두면 됩니다.**

## 이 폴더는 커밋되지 않습니다

PDF 원본이 158MB(단일 최대 39MB)라 저장소에 넣으면 clone이 무거워집니다.
`.gitignore`에서 제외하고 있으며, **원본은 팀 구글드라이브에 보관합니다.**

대신 **색인(`../rag/index/`)은 커밋합니다.** 그래서 평소에는 이 폴더가 비어 있어도
대응방안 생성이 정상 동작합니다. PDF가 필요한 경우는 재색인할 때뿐입니다.

## 자료를 추가하는 절차

1. PDF를 이 폴더에 넣습니다.
2. `../principles_data.json`의 해당 유형 `sources`에 문서를 등록합니다.
   여기에 등록된 문서만 색인 대상이 됩니다.

   ```jsonc
   "R03": {
     "sources": [
       {"doc": "중대재해 위기 커뮤니케이션 가이드라인", "pages": "3p",
        "what": "금지 표현 5종, 유가족 접촉 수칙",
        "verification": "사례 미검증 · 참고용"}   // 검증 안 된 자료면 표시
     ]
   }
   ```
   - `doc` 표기는 파일명과 완전히 같지 않아도 됩니다(부분 일치로 맞춥니다).
   - 유형별 `caution`은 그 유형의 모든 청크에 따라붙어 프롬프트까지 갑니다.
     미국 절차·번역본 등 그대로 쓰면 안 되는 자료는 반드시 적어 두세요.
3. 재색인합니다. `pypdf`가 필요하며 런타임에는 쓰이지 않습니다.

   ```bash
   pip install pypdf
   python -m scripts.build_rag_index --dry-run   # 청크 구성만 확인 (비용 0)
   python -m scripts.build_rag_index             # 실제 색인 (임베딩 비용 발생)
   ```
   * 색인 구축 스크립트는 아직 이 저장소로 옮기지 않았습니다.

## 넣기 전에 확인할 것

- **텍스트 레이어가 있는지.** 스캔 이미지 PDF는 텍스트가 안 뽑힙니다. 실제로 국내
  리콜 이행 매뉴얼 3개가 이 문제로 색인되지 못했습니다(32페이지에서 471자).
- **사용 제약이 있는지.** 외국 법령·절차를 담은 자료는 국내 의무로 오인되지 않도록
  `caution`에 경계를 적어야 합니다.
- **사례의 진위가 확인됐는지.** 확인 안 된 자료는 `verification`에 표시하면 그 표시가
  프롬프트까지 따라가 "미검수 자료"로 다뤄집니다.

## 현재 색인 상태

문서 20종 · 2,705청크 · `text-embedding-3-small`(1536차원)
