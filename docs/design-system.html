크림 바탕 위의 테라코타

기업 리스크를 실시간으로 감시하는 화면은 하루 종일 켜져 있습니다. 그래서 바탕은 눈이 편한 크림 톤으로 두고, 색은 위험도를 말할 때만 씁니다. 서체는 한 벌, 굵기는 네 단계, 모서리는 세 단계 — 이 페이지의 모든 색과 글자는 실제 제품 CSS에서 그대로 가져온 값이며, 여기 보이는 그대로 렌더링돼 있습니다.

서체

Pretendard 한 벌만 씁니다. 한글·라틴·숫자를 같은 설계로 그린 폰트라 "AI RISK BRIEFING 15건" 같은 문장 안에서 글자체가 갈리지 않습니다. 제목용 별도 서체는 두지 않고, 위계는 크기와 굵기로만 만듭니다.

한글 조판 규칙

바탕 계열 3개, 글자 2개, 의미 색 3개가 전부입니다. 테라코타는 강조와 위험에만 쓰고, 나머지 화면은 크림과 종이색으로 조용히 둡니다.

복사해서 쓰기

이 블록 하나만 붙여 넣으면 톤이 그대로 따라옵니다.

:root 토큰 전체

/* 서체: 한글·라틴을 한 벌로 */
@import url("https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/variable/pretendardvariable-dynamic-subset.min.css");

:root {
  /* 서체 */
  --font-soft: "Pretendard Variable", "Pretendard", "Apple SD Gothic Neo", "Malgun Gothic", system-ui, sans-serif;

  /* 글자 크기 */
  --text-caption: .8125rem;   /* 13px */
  --text-small: .875rem;      /* 14px */
  --text-body: .9375rem;      /* 15px */
  --text-emphasis: 1rem;      /* 16px */
  --section-title-size: clamp(1.65rem, 2.5vw, 2.35rem);

  /* 팔레트 */
  --cream: #fbf6ee;
  --paper: #fffdf9;
  --rice: #eee2d2;
  --terracotta: #b85836;
  --terracotta-deep: #8d3f29;
  --sage: #597265;
  --gold: #c88d30;
  --ink-strong: #30251f;
  --ink-soft: #75695f;

  /* 선 · 면 */
  --divider: rgba(109, 82, 61, .14);
  --divider-strong: rgba(109, 82, 61, .22);
  --divider-accent: rgba(184, 88, 54, .22);
  --focus-ring: rgba(184, 88, 54, .35);
  --panel-surface: rgba(255, 253, 249, .88);

  /* 상태 */
  --success-strong: #3f6254;
  --success: var(--sage);
  --success-soft: #deebe4;
  --success-border: #9db6a7;

  /* 형태 */
  --radius-panel: 1.7rem;
  --radius-card: 1.1rem;
  --radius-control: .8rem;
  --shadow-soft: 0 16px 38px rgba(82, 54, 34, .08);
  --shadow-lift: 0 20px 35px rgba(82, 54, 34, .12);

  font-family: var(--font-soft);
  color: var(--ink-strong);
  background: var(--cream);
  font-synthesis: none;
}

/* 굵기 상한을 700으로 묶는다 (기본 bolder는 900까지 올라감) */
b, strong { font-weight: 700; }

/* 위험도 배지 */
.level.critical { background: #f6ddd4; color: #8d3f29; }
.level.warning  { background: #f9edcf; color: #89611b; }
.level.watch    { background: #deebe4; color: #3f6254; }
값은 frontend/src/styles.css에서 추출했습니다. 팔레트와 형태 토큰은 파일 끝의 “캔바 시안 테마 레이어” 블록에, 서체와 크기 토큰은 파일 맨 위 :root에 있습니다. 이 페이지의 Pretendard는 설치된 환경에서만 정확히 보이며, 없을 경우 결이 가장 가까운 Noto Sans KR로 대체됩니다.
